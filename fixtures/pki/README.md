# Folioxide test PKI (TEST ONLY)

**Every key in this directory is a published, test-only key.** The private keys are committed on
purpose so that tests can sign. Never trust these certificates, never install the root anywhere,
and never use the keys for anything but Folioxide's own tests.

- **Generator:** `bash tools/gen-pki.sh` (OpenSSL 3.x). Keys are random, so running it again
  produces different files; commit the whole directory together.
- **Validation:** `bash tools/gen-pki.sh --check` validates the committed files without
  regenerating them (chains, key usage, validity windows, PKCS#12 algorithms, key/cert pairs).
- **Password:** `folioxide` for every encrypted key (`*.key.enc.pem`) and every `.p12`.
- **License:** generated by this project, `MIT` (see `../README.md`).

## Hierarchy

```
root.pem                Folioxide Test Root CA          RSA-3072, self-signed, sha256WithRSAEncryption
├── intermediate.pem    Folioxide Test Intermediate CA  P-384, pathlen 0, signed sha256WithRSAEncryption
│   ├── signer-rsa2048.pem                              RSA-2048  ┐ keyUsage (critical):
│   ├── signer-rsa3072.pem                              RSA-3072  │ digitalSignature, nonRepudiation;
│   ├── signer-p256.pem                                 P-256     │ signed ecdsa-with-SHA384
│   ├── signer-p384.pem                                 P-384     ┘
│   ├── expired.pem     valid 2025-01-01 .. 2025-12-31 only (otherwise a normal signer, RSA-2048)
│   └── wrong-ku.pem    keyUsage keyEncipherment + dataEncipherment only (RSA-2048)
└── tsa.pem             Folioxide Test TSA              RSA-2048, EKU timeStamping (critical)
```

- Subjects are `O=Folioxide Test PKI, OU=TEST ONLY - DO NOT TRUST, CN=<name above>`.
- Serial numbers are random (`openssl ca -rand_serial`).
- All certificates except `expired.pem` are valid from 2025-01-01 00:00:00 UTC to
  2075-12-31 23:59:59 UTC. Dates before 2050 are UTCTime and later ones GeneralizedTime (RFC 5280).
- The root key is RSA and the intermediate key is ECDSA on purpose, so chain verification covers
  both signature algorithms.

## Files

| File | Contents |
|---|---|
| `root.pem`, `intermediate.pem` | CA certificates (PEM) |
| `root.key.pem`, `intermediate.key.pem` | CA keys, unencrypted PKCS#8, for issuing more test certificates |
| `signer-<alg>.pem` | signer certificate, `<alg>` ∈ `rsa2048`, `rsa3072`, `p256`, `p384` |
| `signer-<alg>.key.pem` | its key, unencrypted PKCS#8 (`BEGIN PRIVATE KEY`) |
| `signer-<alg>.key.enc.pem` | the same key, encrypted PKCS#8 (`BEGIN ENCRYPTED PRIVATE KEY`; PBES2, PBKDF2-HMAC-SHA256, AES-256-CBC) |
| `tsa.pem`, `tsa.key.pem` | timestamp authority certificate and unencrypted PKCS#8 key, issued by the root |
| `tsa-root.pem` | trust anchor for timestamp tokens: a **byte-identical copy** of `root.pem` (a copy rather than a symlink, so Windows checkouts work) |
| `expired.pem`, `expired.key.pem` | negative case: validity entirely in the past |
| `wrong-ku.pem`, `wrong-ku.key.pem` | negative case: no digitalSignature or nonRepudiation |
| `signer-rsa2048-modern.p12` | OpenSSL 3 defaults: PBES2/PBKDF2/AES-256-CBC for key and certificates, SHA-256 MAC |
| `signer-rsa2048-3des.p12` | `PBE-SHA1-3DES` for key and certificates, SHA-1 MAC |
| `signer-rsa2048-rc2-40.p12` | `openssl pkcs12 -legacy`: certificates `PBE-SHA1-RC2-40`, key `PBE-SHA1-3DES`, SHA-1 MAC |
| `signer-p256-modern.p12` | OpenSSL 3 defaults, P-256 signer |

Each `.p12` contains the signer key, the signer certificate, and the intermediate and root
certificates. Open them with:

```
openssl pkcs12 -info -noout -passin pass:folioxide -in signer-rsa2048-modern.p12
openssl pkcs12 -info -noout -passin pass:folioxide -in signer-rsa2048-3des.p12
openssl pkcs12 -info -noout -passin pass:folioxide -in signer-rsa2048-rc2-40.p12 -legacy
openssl pkcs12 -info -noout -passin pass:folioxide -in signer-p256-modern.p12
```

## Using the TSA

`tools/tsa/openssl-tsa.cnf` configures `openssl ts -reply` to issue RFC 3161 tokens with
`tsa.pem` (with signing-certificate-v2). See the comment at the top of that file.
